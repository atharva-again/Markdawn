title: MCP
description: Learn the current status of Markdawn MCP support.
---

Direct MCP support for Markdawn is planned, but it is not currently documented as a shipped integration.

Until the integration is ready, use the [Markdawn CLI](/agents/markdawn-cli/) or the [API Reference](/api-reference/endpoints/) to connect tools to Markdawn.

The CLI and API already work with the same pages used by the browser. When MCP support ships, this page will document its endpoint, authentication model, available tools, and security boundaries.
