Direct MCP support for Markdawn is planned, but it is not currently a shipped integration. Do not configure an MCP server from this page.

Until the integration is ready, use the [Markdawn CLI](/agents/markdawn-cli/) or the [API Reference](/api-reference/endpoints/) to connect tools to Markdawn.

The CLI and API already work with the same pages used by the browser. When MCP support ships, this page will document its endpoint, authentication model, available tools, and security boundaries.

## What To Use Today

- Use [Connect AI Assistants To Markdawn](/agents/use-markdawn-with-ai-assistants/) for a terminal-based AI assistant.
- Use the [Markdawn CLI](/agents/markdawn-cli/) for commands, imports, exports, and exact edits.
- Use the [API Reference](/api-reference/endpoints/) to build a direct integration.
