Markdawn gives you one place for the information you want to keep.

You can write pages in the browser, group them in folders, connect related pages, and share them with other people. If you already have notes, you can bring them with you instead of starting over.

If you use AI tools, Markdawn also gives them a way to work with the same pages through the CLI. You can ignore that part until you need it.

## Choose Your Starting Point

- [Create Your First Page](/getting-started/create-your-first-page/) walks you through your first page.
- [Markdown Support](/getting-started/markdown-support/) lists the markdown syntax Markdawn supports today.
- [Bring Your Notes to Markdawn](/getting-started/bring-your-notes/) helps you import an existing markdown file, folder, or Obsidian vault.
- [Organize Pages and Folders](/getting-started/organize-pages-and-folders/) shows you how to keep related information together.
- [Share a Page](/getting-started/share-a-page/) explains how to let someone else view or edit a page.
## The Basic Workflow

1. Create or import a page.
2. Give it a title that describes what it contains.
3. Add the information you want to keep.
4. Put related pages in a folder when you need more structure.
5. Link pages when one page refers to another.
6. Share a page when someone else needs to read or edit it.

Start with one useful page. You can change the structure later.
