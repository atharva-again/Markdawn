---
title: Markdawn vs Outline
description: Compare Markdawn and Outline for team wikis, markdown, self-hosting, and API access.
---

Outline is a focused team wiki and documentation product. Markdawn overlaps with Outline in collaborative knowledge work, but puts more emphasis on markdown content, self-hosting, imports, and a client-neutral API and CLI.

| Decision Area | Markdawn | Outline |
| --- | --- | --- |
| Main job | Shared project knowledge and personal notes | Team wiki and documentation |
| Content model | Markdown pages, folders, and links | Focused collaborative wiki structure |
| Tool access | CLI and API today; MCP planned | Verify current automation options |
| Hosting | Hosted or self-hosted | Verify current deployment options |

Choose Outline for a polished internal wiki with an established documentation workflow. Choose Markdawn when pages also need to hold personal notes, research, project context, and API-accessible content.

## What To Test Before Switching

Compare permissions, public sharing, search, backlinks, simultaneous editing, database requirements, backups, and deployment ownership against a real workflow.

## Verdict

Choose Outline for a focused team wiki. Choose Markdawn when shared project knowledge should remain inspectable and usable outside a single editor.
