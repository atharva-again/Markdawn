---
title: Markdawn vs Obsidian
description: Compare Markdawn and Obsidian for local files, collaboration, portability, and AI tools.
---

Obsidian is a local-first notes application built around a folder of markdown files, plugins, and personal knowledge workflows. Markdawn is a web-based shared content layer for teams that need collaboration, permissions, self-hosting, and a common place for people and AI tools to work.

| Decision Area | Markdawn | Obsidian |
| --- | --- | --- |
| Starting point | Shared web pages and folders | Local markdown vault |
| Collaboration | Shared pages and editing | Depends on sync and collaboration setup |
| Extensibility | API, CLI, and planned MCP | Large plugin ecosystem |
| Ownership | Hosted or self-hosted service | Local files |

Choose Obsidian when local files, offline work, and plugins are the priority. Choose Markdawn when other people need reliable browser access to the same current pages.

## What To Test Before Switching

Check wiki links, attachments, properties, plugins, templates, and embedded content. Markdawn supports markdown files, markdown folders, and Obsidian vault imports.

## Verdict

Choose Obsidian when the vault is the product. Choose Markdawn when shared project knowledge is the product.
