---
title: Markdawn vs Google Docs
description: Compare Markdawn and Google Docs for collaborative documents, connected knowledge, and AI-assisted work.
---

Google Docs is a familiar collaborative editor for documents, comments, and sharing. Markdawn is designed for knowledge that should remain organized, linked, markdown-based, and available to controlled tools after the document is written.

| Decision Area | Markdawn | Google Docs |
| --- | --- | --- |
| Main job | Shared project knowledge | Collaborative documents |
| Organization | Pages, folders, and links | Files, folders, and Drive search |
| Collaboration | Shared pages and editing | Mature document collaboration |
| Tool access | CLI and API today; MCP planned | Verify current automation options |

Choose Google Docs for agendas, proposals, shared drafts, comments, and approvals. Choose Markdawn for ongoing project pages, research, decisions, and notes that should stay connected.

## What To Test Before Switching

Move one project first. Check headings, tables, comments, images, links, and sharing rules.

## Verdict

Choose Google Docs for collaborative documents. Choose Markdawn for the knowledge that connects decisions and project pages.
